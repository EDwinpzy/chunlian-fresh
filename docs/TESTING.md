## 4. 不接受的交付结论

- 顾客 Android 仍只是 WebView 页面，却宣称完成原生 Android 客户端。
- 把二维码展示、顾客截图或顾客侧确认当作已收款。
- 退款实际未退回就记录为成功或减少实收。
- COD 送达时强制标记已收款，无法保留送达未收款。
- 资金结果只由客户端假状态决定，没有商家核实和服务端记录。
- 缺少迁移、源码、幂等或恢复路径却宣称交付完成。
