# 春连鲜选 · 图片素材生成提示词

风格锚点来自设计规范 v1.0（方案 01 有机鲜绿）。

---

## 1. 主提示词（复制这一段即可）

> 为一款社区生鲜电商 App「春连鲜选」生成商品图片素材。整体视觉风格：**自然有机、干净通透、可信的精品生鲜零售感**，参考 Apple 产品页的克制与留白，以及农场直供品牌的质朴调性。画面主色为**深墨绿 `#245947`**与**奶油白 `#F7F8F4`**，可点缀少量**暖金 `#D7A766`**；除此之外不出现其他高饱和颜色。构图规则：**单品居中、主体占画面 70%–80%、四周留白充足**，背景为**纯白或极浅灰白（`#F8F9F5`）**，不要道具、不要桌布、不要文字水印、不要边框。光线为**柔和均匀的自然光，从左上方打光**，阴影极淡且柔和，不出现硬阴影和强烈反光。质感要求：**真实食材的新鲜质感**——蔬菜叶片带细微水珠与自然纹理，蛋壳有细微斑驳，肉类呈现冷鲜的湿润光泽；不要塑料感、不要过度修图的假亮、不要油画或插画风格。输出**正方形 1:1、800×800 以上、PNG 或 JPG、白底可直接抠图**。需要生成的具体商品（每样一张）：本地小青菜、沙瓤番茄、散养土鸡蛋、冷鲜土鸡半只、带泥莲藕、紫皮茄子、鲜香菇、嫩豆腐、小葱、生姜、红皮土豆、西兰花、本地草莓、五花肉、活虾、玉米、山药、小米椒、蒜头、胡萝卜。另外单独生成 3 张**主推场景图**，比例为 **4:3、1200×900**，允许出现场景感（清晨的菜地、木质砧板上的食材、厨房台面），但仍需保持上述色彩与光线规则、主体明确、不出现人物正脸。

## 2. 分段续写（按需追加在上一段后面）

### 2.1 品牌标识

> 在同一视觉风格下，生成品牌标识：横版 Logo（600×200 透明 PNG），文字为「春连鲜选」，字体为现代无衬线中文黑体、字重中等、字距略松，配色为深墨绿 `#245947`，左侧可配一个极简的叶片或菜篮线性图标（1.7px 描边、圆头圆角）。同时生成方形印章版（512×512 透明 PNG）：深墨绿方块、四角微圆（圆角 6px）、内部白色「春连」二字，风格接近现代中式印章但保持极简，不要繁复纹样。

### 2.2 分类图标

> 生成 8 个分类图标（每个 96×96 透明 PNG）：时蔬、肉禽、蛋奶、水产、净菜、水果、粮油、特惠。统一为**线性描边风格、1.7px 描边宽度、圆头圆角、深墨绿 `#245947` 单色**，图形高度抽象简洁、笔画粗细一致、视觉重量均衡，不要填充色块、不要阴影、不要渐变。

### 2.3 头像占位

> 生成 4 张用户头像占位图（每张 200×200）：1 位 40–50 岁的中国店主（男性，穿深色围裙或衬衫，表情亲和，半身或头部特写，背景为奶油白 `#F7F8F4` 纯色），3 位顾客（不同年龄性别，自然光下的证件照式头像，背景同为奶油白纯色）。风格为**写实但柔和**，不要夸张表情、不要商务影棚感、不要卡通化。

### 2.4 收款码占位

> 生成 1 张收款二维码占位图（500×500）：白色方形底、四角圆角 12px、中央为深墨绿 `#245947` 的二维码图形，四个定位角清晰，图案为规则的黑白模块结构（不需要真实可扫），画面干净无多余装饰。

## 4. 验收要点

素材生成后按这几条筛：

1. **底色一致**——所有商品图的白底要是同一个白，否则在商品网格里会花。建议统一用 `#FFFFFF`，不要有的偏灰有的偏暖。
2. **主体大小一致**——同一网格里的商品视觉重量要接近。小青菜不能占满画幅而土豆只占一半。
3. **色相不跑偏**——素材本身可以五彩缤纷（食材本来就有颜色），但**背景和光线的色温要统一**，不要一半冷调一半暖调。
4. **不要文字**——素材上不要出现任何文字、水印、logo、价格标签。所有文字信息由界面渲染。
5. **4:3 场景图不抢戏**——主推图可以有场景，但主体必须清晰，且不要出现人脸特写（涉及肖像权）。

## 5. 落地方式

素材就位后按 `assets/design/` 现有目录结构放置：

```
assets/design/
  generated-icons/
    customer/          # 顾客端分类图标
    merchant/          # 店主端图标
  goods/               # 商品图 P-01 ~ P-20（已归一化，应用用这个版本）
  goods-source/        # 商品图原始版本，留档
  hero/                # 主推场景图 C-HERO-01 ~ 03
  brand/               # Logo、印章
  avatars/             # 头像占位
  goods-manifest.json  # 素材包自带的清单
```

安卓端通过 `CustomerAssetIcon` / `MerchantAssetIcon` 读取（这两个组件已做可见区域自动裁切，素材四周的透明留白不会导致图标看起来偏移或过小）。
